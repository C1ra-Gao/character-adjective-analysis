# Version and attribution boundary

This directory contains a **2026 portfolio repair** of a **2023 PfL course
submission**, not the original submission. Original files remain outside this
directory and are not copied into the public project.

The course supplied the project task and method requirements, including model
choices, the context-window rule and positive/negative seed words. The Dune input
was provided for the assignment. These are not claimed as original research
contributions.

The author confirms that the **2023 code implementation was independently
written by the author**, as the student completing the assignment. No course
template-code authorization is needed for this implementation. This authorship
statement is based on the author's explicit confirmation, not inferred from
code style.

The 2026 repair and verification were implemented with OpenAI Codex assistance.
This assistance applies to the **2026 repairs, tests and portfolio documentation**,
not to the independently written 2023 implementation. No historical time-spent
estimate or unconfirmed tool-use history is invented.

The method remains NLTK Punkt + py3langid, spaCy small PERSON/ADJ extraction,
two-token context on each side, pair-event PMI and medium-model static-vector
similarity to the supplied seeds. No training, BERT, LLM inference, coreference
or new sentiment algorithm is introduced.

Raw books, preprocessed books, language-rejection logs and local environments
are kept outside this directory. Only reviewed aggregate outputs are included.
Dune is used only for local validation of the supplied course copy; that copy
and its full-text derivatives are not redistributed. No GitHub push is made.

The Picture of Dorian Gray input is the historical Project Gutenberg eBook
174 copy supplied with the submission. Source:
https://www.gutenberg.org/ebooks/174 . Gutenberg lists the work as public domain
in the USA; its distribution conditions and local copyright rules still apply:
https://www.gutenberg.org/policy/license.html . Neither book text is licensed
as the portfolio author's code.

The author's confirmation resolves the earlier implementation-ownership concern.
No further course authorization is awaited for the author's code. Course PDFs,
assignment text, third-party book texts and private submission information remain
excluded. No license is assigned to those materials.

The candidate has not been published. Final author approval is required before
any GitHub push. No repository-wide open-source license has been chosen on the
author's behalf. See `docs/RELEASE_REVIEW.zh-CN.md` for the current release review;
earlier audit/verification reports record the information available at those stages.
